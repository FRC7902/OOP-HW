# OOP Homework

Starter code for **Intro to Object-Oriented Programming**.

`src/Car.java` is the example class from the lesson, and `src/Main.java` creates and uses two `Car` objects.

## Running it
1. Open this folder in **VSCode WPILib**
2. Open `src/Main.java`
3. Click **Run** above `public static void main`

## Your task
Full instructions are in the OOP Homework document. In short:
1. Make your own branch, named `firstname-oop`
2. Add a new class of your own in `src/` (not a `Car`!)
3. Create and use two objects of your class in `main`
4. Commit and push your branch
